Pertanyaan umum

TablePID beneran gratis?

Ya! TablePID 100% gratis digunakan. Gak ada biaya tersembunyi, gak ada tier premium.

Data saya aman?

Tentu saja. Kredensial kamu dienkripsi di OS keychain. AI provider hanya menerima prompt kamu, bukan kredensial.

Database apa aja yang didukung?

PostgreSQL, MySQL, MariaDB, dan SQLite. Lebih banyak lagi menyusul.

Bisa dipake offline?

Bisa! Semua fitur bisa jalan offline kecuali AI. Untuk AI, kamu bisa pakai Ollama lokal untuk full offline.

Source code-nya proprietary, tapi aplikasinya gratis untuk digunakan dan didistribusikan.
